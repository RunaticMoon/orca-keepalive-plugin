Cache Keepalive

유휴 Claude 터미널에 캐시 만료 직전 짧은 메시지를 보내 프롬프트 캐시를 유지합니다.

현재 워크트리

워크트리 정보를 불러오려면 새로고침을 누르세요.

이 정보는 적용 대상을 알려줍니다. keepalive 실행 상태는 대시보드나 명령으로 확인하세요.

상태 확인과 켜기·끄기

1. 명령 팔레트 열기

⌘J다른 OS: Ctrl+Shift+J

명령 팔레트에 Cache Keepalive를 입력하세요.

명령 목록 8개
Cache Keepalive: Open Dashboard
상태와 설정을 볼 수 있는 대시보드를 엽니다. 단축키 ⌘⌥⇧J다른 OS: Ctrl+Alt+Shift+J
Cache Keepalive: Pause/Resume All
전체 keepalive를 켜거나 일시정지합니다.
Cache Keepalive: Pause All
모든 워크트리의 keepalive를 일시정지합니다.
Cache Keepalive: Resume
일시정지를 해제합니다.
Cache Keepalive: Toggle Current Worktree
현재 워크트리의 설정을 반대로 바꿉니다.
Cache Keepalive: Turn On for Current Worktree
현재 워크트리에서 keepalive를 켭니다.
Cache Keepalive: Turn Off for Current Worktree
현재 워크트리에서 keepalive를 끕니다.
Cache Keepalive: Show Status
현재 상태를 Orca 알림으로 확인합니다. 워크트리마다 현재 위치 ▶와 실제 켜짐 ⚡, 다음 전송 시각, 확인 필요 개수를 함께 보여줍니다.

기본으로 켜져 있는 탭 이름에 ⚡ 표시는 keepalive가 적용되는 Claude 탭 이름 앞에 ⚡를 붙여 칸반 카드에서도 보이게 합니다. 대시보드 설정에서 끌 수 있습니다. 직접 지정한 탭 이름은 복원되지 않을 수 있고, 끄거나 조건이 안 맞으면 Orca 자동 이름으로 돌아갑니다.

Orca 터미널에서 확인·설정

플러그인이 실행 중이면 아래 명령 파일이 자동으로 생깁니다. Orca 터미널에 입력하세요.

  • 상태 확인
    node ~/.orca-cache-keepalive/keepalive.mjs status
  • 전체 켜기
    node ~/.orca-cache-keepalive/keepalive.mjs on
  • 전체 끄기
    node ~/.orca-cache-keepalive/keepalive.mjs off
  • 현재 워크트리 상태
    node ~/.orca-cache-keepalive/keepalive.mjs here
  • 현재 워크트리 켜기
    node ~/.orca-cache-keepalive/keepalive.mjs here on
  • 현재 워크트리 끄기
    node ~/.orca-cache-keepalive/keepalive.mjs here off
  • 현재 워크트리 기본값 사용
    node ~/.orca-cache-keepalive/keepalive.mjs here default
  • 대시보드 주소
    node ~/.orca-cache-keepalive/keepalive.mjs url

Windows 상태 확인

node %USERPROFILE%\.orca-cache-keepalive\keepalive.mjs status

플러그인 전체 끄기

Settings > Plugins > Cache Keepalive에서 스위치를 끄세요.

Orca 패널 API 제한으로 이 패널에는 실시간 상태와 토글을 표시할 수 없습니다. 대시보드·명령·터미널 명령을 사용하세요.

Keepalive 메시지는 사용량을 소비하고 대화 기록에 남습니다.
